Trang đang mở trong trình duyệt của Zalo, ở đây không gửi hoặc tải file được. Bấm nút ⋯ (hoặc ⋮) ở góc trên rồi chọn "Mở bằng trình duyệt" (Chrome hoặc Safari).
Mở bằng Chrome
Mỗi tài liệu được xuất thành một file PDF riêng, tên file là "Tên hồ sơ - Tên tài liệu". Bấm vào ảnh trang để cắt lại hoặc đổi kiểu ảnh. Ảnh được xử lý ngay trên máy và lưu tạm trong trình duyệt, tải lại trang vẫn còn.
